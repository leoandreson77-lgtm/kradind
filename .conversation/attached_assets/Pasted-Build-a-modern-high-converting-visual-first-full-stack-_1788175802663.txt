### 1. Visual & UX Design Directive (Must be Stunning & Modern)
- Design Aesthetics: Clean, sleek, modern, and adventure-focused. Use depth, glassmorphism (`backdrop-blur-md`), subtle borders (`border-white/10`), rounded corners (`rounded-2xl` / `rounded-3xl`), and layered shadows (`shadow-xl`).
- Color Palette:
  - Deep Forest Green (Brand Base): `#0F3A2E` / `emerald-950`[cite: 1, 2]
  - Sunset Orange (Primary CTA & Accents): `#FF6B35` / `#FF8C42`[cite: 1, 2]

- Interactive UI Elements: Soft hover transformations (`hover:scale-[1.02] transition duration-300`), pulse indicators for live status radar[cite: 1, 2], and animated gradient highlights.

### 2. Tech Stack & Architecture Requirements
- Framework: Next.js 14+ (App Router, TypeScript)
- Style: Tailwind CSS + Lucide React Icons[cite: 1, 2, 3]
- Database & ORM: Prisma ORM with SQLite (or PostgreSQL) for booking records, dynamic batch status, user queries, and live trail updates
- Content Management (CMS): Built-in JSON-backed CMS or Sanity.io integration with API routes for managing treks, itineraries, and media
- Search Engine Optimization (SEO):
  - Next.js Metadata API for dynamic `<title>`, `<meta name="description">`, OpenGraph (`og:image`, `og:title`), and Twitter Cards
  - JSON-LD Structured Data (`TouristAttraction`, `Event`, and `BreadcrumbList` schema) for rich snippet search results
  - Dynamic `sitemap.ts` and `robots.ts` routes
